# 🌍 ClimateDashboard: Global Climate Change Analytics Dashboard

An interactive climate analytics project built while exploring **Python, Pandas, Plotly, and data visualization**.

## 📖 About the Project

Using the **Our World in Data CO₂ dataset**, this project explores how carbon emissions have evolved over time and how different countries contribute to global emissions.

The goal of this project was not only to build visualizations, but also to understand the fundamentals of data analysis and storytelling with data.

## 🚀 What I Learned

### 📊 Data Analysis with Pandas

* Loading and exploring datasets
* Handling missing values
* Filtering and selecting data
* GroupBy and aggregation
* Sorting and ranking

### 📈 Data Visualization

* Line charts
* Bar charts
* Scatter plots
* Correlation heatmaps
* Interactive world maps
* Animated visualizations

### 🌍 Climate Insights

* Global CO₂ emission trends
* India vs China vs USA comparisons
* Top CO₂ emitting countries
* GDP vs CO₂ relationships
* Population vs CO₂ analysis
* Geographic visualization of emissions
